# 工具结果复用边界

成员决定查询内容，引擎控制重复外部请求。人物特质不参与缓存匹配，也不要求成员为了节流避免调用工具。

## 网页工具

`search` 和 `read_page` 在同一 Toolbox 进程内采用 5 分钟内存缓存。身份包含聊天、服务地址、凭据、工具端点以及实际请求参数（整体哈希，不保存明文缓存键）。JSON 键顺序不影响身份；搜索词、URL 及其查询参数不做语义归一。不同聊天不共享。

成功完成后开始计时；命中不续期，过期重新请求。refresh=true 绕过旧结果，成功后刷新缓存。相同的并发请求等待同一份结果。等待者取消不取消发起者；发起者失败时等待者也收到错误，下一次新调用可以重试。网络失败、无可用网页正文不缓存；成功返回空搜索列表仍是一份有效搜索快照。服务重启清空缓存，无数据库迁移或持久缓存。

每次成员调用分别保存 tool_run；`retrieved_at` 是原结果取得时间，`reused` 标记本次是否复用。只有实际外部请求进入已有预算预留与结算；缓存命中和等待不再收费。收到非成功 HTTP 状态或有效空搜索时释放预留；成功有结果才结算费用；未收到明确结果或结构异常保留未知预留。活动摘要将复用显示为“查看已有搜索结果”或“查看已有网页内容”。

## 其他工具

- 当前记忆、工作、聊天历史和最新成果继续读取数据库，不缓存动态状态。
- 历史工具结果和指定历史版本是明确的历史快照，可直接回读。
- 写入、消息发送、委托、预约等仅保留同一 work/member/tool_call 的恢复保护；新调用不会仅凭指令文字相同被合并。
- 不改变工具权限、个人记忆隔离、暂停要求及不确定写入禁止盲目重放的规则。

## 材料上下文

公开工具索引带调用时间、参数和工作目的；联网结果另带原始取得时间。搜索概览按条保留标题、链接、原始摘要和来源元信息，避免第一篇长文挤掉其他来源；完整结果仍留在数据库供分页读取。共享的是材料，不是要求其他成员沿用分析的指令。

## 本地验证

`web_cache_test.go` 覆盖精确匹配、跨成员独立记录与单次计费、5 分钟过期、并发复用、聊天/端点/URL 参数隔离、失败重试、等待者取消、网页空正文不缓存、搜索来源完整展示，以及新委托/预约与同次调用重放的区别。完整测试还覆盖个人记忆权限、上下文大小和恢复行为。测试使用本地模拟服务，不消耗付费搜索或模型调用，也不证明实际群聊表达已经更丰富。
