# 个人活动和独立交流

本次修改的目标是让成员能从自己的兴趣、经历和对人的了解出发行动，也让一条消息不再天然等于“一人一轮”。没有添加人格分数、兴趣等级或发言配额。

## 删除了什么

- `speak / explore / revisit / pass` 前置参与分类和它专用的模型配置。
- `already_spoke`、首轮发言提示、按 @ 产生的固定排序、等所有成员判断完再逐个发言的队列。
- 研究结束后再次调用模型审批是否分享的阶段。
- 沉默后逐渐退避到六小时的闲时调度，以及全局两个工作位、最多一个自主工作位的固定限制。
- 工具之后因为别的房间有真人请求就退出整项行动的旧逻辑。不同成员本就能够独立执行；相关成员的个人活动可在真人到来时中断并保存断点。
- 把 `message` 作为最终返回格式的默认要求。旧断点兼容这个字段，新生成使用 `send_message` 发消息，单独结束行动。

正式数据还清理了“随便聊聊”中遗留的“群聊回复应真正承接其他成员……避免重复”统一表达要求，仅移除这句话，保留当前话题。人物说明、聊天原文和成员各自的经历没有随之重写。

## 当前实际执行

每位成员有一个个人活动时钟，沿用 `DROPBY_EXPLORE_INTERVAL`，默认 30 分钟。多个房间不会创建多份同一个人的闲时机会，沉默也不改变间隔。具体预约仍按本人的工具调用和到期时间运行。时钟提供机会，模型可以直接结束、探索、创作或交流，不按时钟要求发消息。

个人活动默认输入包含本人设定、自己的近期关注、相关经历、对真人的相处理解、自己的未完事项，以及可交流的人和房间索引。聊天历史通过工具按需查看。近期关注是自然语言；修改它不修改人物设定。关系笔记仍由成员分别持有，沿用原来源、修订和纠正机制。默认窗口提供摘录，完整历史、资料和作品可回读。

成员可使用既有搜索、网页读取、作品、记忆和预约工具，以及新的 `read_conversation` 与 `send_message`。消息是行动中的一个工具结果，可以发完后继续做事或接着交流。生成期间收到新的同伴发言，尚未发送的草稿会先取得最新现场，再由本人选择如何处理；系统不按内容相似度删改台词。

群聊成员独立行动；研究和预约属于执行人，不占用整群的工作位置。个人活动或研究发出消息后产生持久的聊天唤醒，其他成员不必等待原研究结束。某人的模型或工具出错不能使其他成员失去行动机会；普通工具错误交还本人处理，故障与额度记录由界面展示。

个人研究和作品的 `conversation_id` 可以为空，表示还没有分享对象。作品通过真实消息分享后，对应版本可在那个聊天中发现和阅读；后来未公开的草稿不会替换历史分享。

## 保留的执行边界

- 同一个成员的行动串行，避免两个房间同时覆盖其经历。不同成员没有全局轮流屏障。
- 同次消息工具调用由实际 call ID 确认；消息、唤醒和最终行动回执在对应事务中保存。恢复重复消费同一次调用不会多发消息，新的调用仍允许表达相同观点。
- 真人当前指示、暂停、成员归属、版本与原始来源、实际工具参数和总费用账本继续生效。
- 上下文窗口只放索引与相关内容；必要时沿用 Responses 原生压缩。保存的历史原文和工具结果不因窗口收缩删除。
- 服务仍须运行，电脑休眠时不能继续联网。正常每周预算和既有临时开发预算保持原值。

## 验证与实际观察

自动回归包括：三个后台成员阻塞时第四位仍能实际回复；两人接话不等待第三人；研究者边分享边继续研究时同伴能够回复；模型与工具故障续接；发送后崩溃不重复；合并唤醒不漏读对方的新话；新现场在发送前交还本人；个人经历及纠正召回；已公开与未公开作品版本的读取范围。

2026-11-07 的真实 API 验收采用从本地读取的裴船、石粒原始人物说明，没有修改人物来迎合测试。实验数据库与正式聊天分开。只提供一段过去的相处偏好，不给当前任务、选题或发言顺序。

- 裴船做了“给雨换个屋顶”的声音玩具并主动私聊分享。
- 石粒自主搜索视觉错觉资料，做了“两块灰”的视觉实验并分享。
- 连续群聊中，两人从声音影响视觉聊到水洼、雨声和灰块，使用同一行动内的消息工具往返。运行记录与发言数量不再一一对应；原始记录中仍能看到比较工整的两人接话和解释性措辞，不能据此声称长期相处已经完全自然。
- 实验中一次记忆来源错误没有挡住消息。修复了本人个人探索资料用于后续聊天经历时被误当成其他聊天来源的问题，并加入回归。
- 真实调用累计估算费用约 $0.3412，包含初次个人探索与三次连续群聊比较；正式聊天没有插入验收台词。

正式数据库的副本完成迁移演练：人物、消息、成员关系、记忆、记忆版本、作品、用量、工具记录逐行哈希一致，外键检查无错误，八个聊天接口均能读取。

同日更新 8090 后，没有插入催促消息，正式成员自然产生了不同选择：爱情导师私聊分享原创故事《不顺路》，明天你好查阅并分享熊蜂玩木球的研究，裴船查阅 NASA 数据声音化导览、保存小卡但没有发消息，青雉和石粒选择继续已有话题，并在群里接住对方的新发现。五份个人活动均已完成。这个结果证明了不同选题、交流对象和“不分享”的路径都实际走通，不代表所有发言的语气已经理想；现有长聊天中仍出现较多解释和限定措辞。

正式观察中还发现，个人活动发到群里的消息被旧的记忆来源校验挡住。修复后，个人活动可用本人已加入聊天的真实记录形成经历；未加入的聊天仍不可读。该故障发生时消息已送达，成员后来也继续完成了活动，没有拖住同伴。

浏览器检查包含个人资料中的近期关注、朋友动态、个人作品分享后的聊天成果入口和 HTML 实际交互。1280 像素桌面与 390 像素窗口均检查；窄窗口无整页横向溢出，视觉实验按钮实际改变了预览中的背景与状态。新增消息工具的动态摘要按实际发送结果显示，并消除摘要里的 Markdown 链接语法。

这些验证确认执行机制和短场景行为。尚未验证数天相处后的主动频率、话题重复率或长期费用；真实体验仍需观察本人长期使用后的自然表现，不能用短时加速调用代替。
