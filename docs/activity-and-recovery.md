# 聊天恢复、朋友动态与资料一致性

2026-11-07。沿用已上线的浮光 UI：头像浮卡、浮动详情、原生编辑弹窗及现有青绿视觉。本轮没有更换聊天布局，也没有增加任务看板或人格状态机。

## 行为变化

- 成员参与判断失败单独保留。正常 `pass` 不再要求有效接话对象；主动参与引用无效时只允许本人纠正一次，纠正不开放工具，不能重放副作用。其他成员的正常判断（包括沉默）仍成立；已有公开回复不会因后续判断失败变成整轮失败。全员首次判断失败、取消、预算、修订、存储与记账错误仍向执行层传播。
- 动态按人物近况、真实后续、实际行动呈现。动作摘要从数据库记录派生，不额外调用模型，不持久化另一套进度。工具安排成功与目标工作的当前状态分开；读取记录、整理经历等放到第二层。内部指令、ID 和 JSON 在技术详情中保留。
- 未完研究阻止自动结束职责，并返回 `waiting` 和具体工作；失败研究也不能算已完成。本人已结束的临时职责可重复确认，但结束后不能继续委托。取消自己已完成/已停止的工作保留原终态和成果；其他人、其他聊天、未知目标和正在执行的工作不能借幂等绕过权限。
- 对于历史收尾失败，界面同时解释当时状态与现在是否结束，不修改原错误记录。取名、简短意见等可以直接在聊天里邀请，不再被共同事项提示强制转换为后台研究。
- 朋友列表、头像浮卡、群成员列表及成员选择器均读取当前人物说明。当前聊天的关注仍带来源单独显示；一次观点不会因此写入永久资料。SSE 更新浮卡与行动详情时保留当前阅读位置、展开项和焦点。
