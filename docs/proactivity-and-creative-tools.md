# 主动后续与聊天创作工具

实现日期：2026-11-07（Asia/Shanghai）。本次延续已经确认的主动性方案和中性色聊天界面，不引入新的性格分数或人物状态机。

## 角色怎样继续一件事

新消息和实际工作结果继续通过现有队列处理。成员可以用 `schedule_followup` 为具体关注安排一次重新考虑，也可以在参与判断时选择安静地安排后续，无需先发一句话。到期先由本人读取最新上下文，允许放弃、改变方向、行动或开口；本人真正发布消息后，同伴仍可自由接续。

`cancel_work` 只允许成员取消自己在当前聊天的未执行研究或后续。真人改变话题不会抹掉已安排的关注；用户明确取消对应方向时，可以停止研究及后续。执行中的后续被新消息打断后会重读，拒绝过时的草稿。明确要求恢复时，以新真人指令作为新的执行来源。

闲时探索默认起始间隔 30 分钟，此后逐渐放缓，最多间隔 6 小时；新会话仍有较早的初次机会。真人新交流重置闲时间隔，BOT 自己的消息不会不断重置。具体后续不必等待闲时扫描，服务恢复后也不会补发每一次错过的定时机会。

## 预算与连续行动

每天总估算上限仍为 3 美元，自主后台默认最多使用其中 1 美元。总预算与自主预算在同一事务中预留并按实际 token 用量结算，联网工具也计入。已有历史用量保留；自主用量从升级后的调用开始单独计量。

工作的引用来源与计费归属分开保存：后续引用真人旧消息，不代表后续永远可以占用真人预算。自主工作衍生的工作、分享和工具调用继承自主归属。每名成员在同一触发下安排的研究和复看次数有累计上限，分享已有成果不挤占实际工作次数；自主公开消息、问题和私聊也累计计数。预算与次数是执行边界，不决定角色观点。

两个全局执行位置中，自主后台最多同时占用一个，给真人新聊天留出执行位置。预算不足、失败和角色主动选择安静分别记录；后台额度不足不会冒充角色不愿回应。

工作实际完成并已用工具安排后续时，原工作不再因模型填写 `unfinished` 而重复执行。单纯等待公开分享，也不会再自动创建一份研究。这个边界来自本次真实模型验收中观察到的重复工作，而非假设中的扩展需求。

## 选择题与 HTML

所有成员都具备保存和修改本地文稿及 HTML 的能力。问题工具继续遵循当前聊天一次一个开放问题，支持选项、自由回答和自然改聊其他话题，没有额外的跳过按钮或强制问卷。

`save_artifact` 支持 `markdown` 和 `html`。旧作品保持 Markdown；新作品默认 Markdown，修改时省略格式会继承原作。所有版本保留完整源码和实际作者、来源，工具返回简短的真实成果入口，避免把整份 HTML 再复制进模型上下文。

保存成果与公开分享分开。安静创作的结果可以在成果集合里主动查看，但不会自动变成聊天消息。只有实际公开消息引用了成功保存记录，才在该消息下面显示成果卡片。卡片固定到当时分享的版本，后来的未分享版本不会替换它。

HTML 详情提供预览、源码、复制、版本选择和对应版本下载。切换源码与预览保留页面当前交互；新的版本出现时提示查看，不重置正在操作的页面。继续聊作品保留输入框已有草稿。

预览使用 `sandbox="allow-scripts"` 及响应 CSP 的双重边界，页面脚本可以操作自己的内容，不能读取宿主聊天 DOM、存储或 API，不能导航父页面、开弹窗或提交表单。CSP 限制常见外部资源、联网 API、子框架和工作线程。浏览器仍允许框架导航自身，因此这里不声称完全网络隔离；下载的 HTML 是原始文件，在应用外打开时不受此预览沙箱保护。

`go test -race -count=1 -json ./...`：63 个顶层测试通过，包含子测试共 77 项通过，4 个真实服务测试默认跳过。`go vet ./...`、JavaScript 语法检查、`git diff --check` 和构建通过。自动测试涵盖旧数据迁移、版本与下载、公开分享与安静创作分离、跨群引用、问题交互，以及主动后续的预算、来源继承、暂停、恢复、前台执行位置和重复安排回归。

显式启用的真实模型测试 `TestLiveCreativeToolsAndFollowup` 使用隔离的合成聊天：

1. BOT 实际调用选择题工具，提出两个风格选项。
2. 收到自由文字回答后，实际保存《允许临阵脱逃》的完整 HTML，按钮可以切换三句反攻略。
3. 实际调用 `schedule_followup` 约定一分钟后复看；没有新的真人消息时，后续到期并完成了重新考虑。
