# 角色群聊与聊天界面改进

实现与验收日期：2026-11-07（Asia/Shanghai）。本次延续已确认的中性色聊天界面方向，依据本机 Grok Bot 的实际创建、问题消息、群聊及资料界面观察；没有将竞品的外观当作其内部机制的证据。

## 从分别回答到参与一段交流

原实现已经提供了其他人的发言，问题出在参与流程：未发言的成员仍被鼓励独立回答真人原问题；每次只留下一个人的意图；首位探索者被强制转换为发言；某人生成空消息会结束全群机会。

现在，每位成员独立观察近期交流和相关历史，结合自然语言人物说明、可见经历、当前关注与实际工作，选择零条、一条或多条消息。意图保留到实际行动前；后发言的人会重新读到同伴的新消息，可以改变接话对象、缩短认同、继续某个细节或撤回。允许接梗、共情、附和与安静，没有中央相似度分数或固定的支持／反对角色。

观察过的位置与发言分开保存。当前状态和目标是一小段自然语言，只有变化时更新，可以明确清除，且必须关联本聊天的真实消息或成功工具记录。代码校验来源存在及范围；描述是否贴切仍是模型判断。这份当前关注按聊天隔离，成员人物说明与既有可携带经历保有跨场景连续性。

消息上限按实际发布计算，安静、撤回和安静研究不挤掉其他成员的机会；另保留有限行动次数、超时及每日预算。全员选择安静是正常结束，模型错误单独记录。新消息、实际进展和后续自主机会可再次触发观察。

人物修改会拒绝旧设定生成的草稿。如果没有新真人消息接替原问题，同一工作会按新设定重试；有新消息时旧机会仍被替代。重试不会把原消息中的旧偏好再次覆盖到更新的人物说明。

## 界面与偏好

- 白色成员气泡、蓝色用户气泡、中性背景，区别导航、交流与详情。聊天／朋友分开浏览，支持搜索。
- 12 个默认头像图案、6 种颜色、PNG/JPEG 图片上传；资料中可以修改名字、头像和人物说明。浏览器只提交裁剪后的缩略图。
- 创建仅需名字和头像，立即进入一条带可选问题的相识消息，不等待模型。点选、自由回答或改聊其他话题均使用普通消息，没有跳过按钮。
- 明确的长期相处偏好合并到同一个成员的资料；临时话题不自动永久化。问题回答归属提问成员，一次只显示一个开放的问题。
- 点击标题或头像进入详情，显示当前关注及其实际来源。宽屏并排，窄屏详情独立展开；手机可往返聊天列表、聊天与资料。
- 引用回到原消息、每个会话保留未发送草稿、输入法回车保护、读旧消息时不自动滚到底部。
- 图标保存在本地并保留许可，没有新增前端运行时框架或外部字体依赖。

## 真实模型观察

真实运行使用现有 OpenAI `gpt-5.6-sol` Responses 配置，快速阶段与深入阶段的配置保持原样。数据保存在独立的 `data/character-acceptance/`，未混入正式群聊。

验收给桃子、周屿、林间三位成员设置不同的关注与表达起点。前三条消息是明确的测试开场，后续成员消息由真实模型产生。两轮共 28 次调用，估算 0.3874 美元；两次首条实际回复约 10.17 秒和 10.10 秒。整轮分别约 23 秒和 33 秒；当前仍不是逐 token 流式输出。

第一轮出现以下接续：

1. 林间提出“看见第三种颜色就拐弯”。
2. 周屿引用林间，补充颜色不好看可以作弊，并把重点转到“不让规则接管周末”。
3. 桃子引用周屿，将临阵脱逃延伸为“隐藏结局”。
4. 三人随后均选择安静，未机械填满消息上限。

下一轮转为荒诞的“反攻略”标题共创，桃子、林间、周屿连续引用并改写上一个版本，最后又由桃子接成“情况通报”。成员保存了关于规则自行失效、反攻略创作的当前关注。

这组对话验证了真实的同伴引用、改写与自然收束；没有将一次成功样例概括为长期人格、关系演化或趣味均已成立。

## 本地更新与已有数据

正式服务已更新到本次构建，仍使用 `127.0.0.1:8090`、原模型配置和每日 3 美元上限。更新前保存了 SQLite 完整备份及原二进制。更新后核对原有 3 位成员、4 个会话、23 条消息；23 条消息的正文哈希全部一致，新状态接口可用。

另修复了一条已知的旧版偏好遗漏：“爱情导师”在原真人消息中已被明确要求具有浪漫、有趣及文学气质，但旧版本只记入聊天方向。此次依据该条原消息补回了人物资料，身份、头像和聊天正文未更改；修复前后值及来源 ID 保存在本地备份目录。没有批量猜测或改写其他成员的历史偏好。

## 保留的边界

当前关注是模型根据实际上下文形成的描述，并不是可以独立测量的人的心理状态。安静、主动、个性差异与有趣程度仍需长期观察，不能由发言次数证明。事实核对继续只处理来源和实际行动，不替成员决定观点。

关闭浏览器不停止本机后台；电脑休眠或服务停止时无法继续。保持每日 3 美元的正式运行上限，未更换为廉价模型。头像上传、资料编辑及问题工具没有扩大任何第三方账户或外部发布权限。
