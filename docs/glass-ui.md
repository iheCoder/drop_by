# 浮光界面

实现用户选定的第一张设计稿。采用现有 Go 服务与真实数据，不引入演示消息到正式数据库。视觉素材与 UI 代码一起嵌入二进制，无外部字体、图片或 CDN 请求。

## 操作与状态

- 玻璃导航和会话列表保留在聊天左侧；窄窗口通过返回入口查看列表。
- 点击头像使用原生 popover 就近展示姓名、状态、私聊与编辑入口。打开浮卡不改变聊天宽度；位置按视窗约束，Escape 返回入口。
- 创建群聊从全局加号进入。搜索仅过滤候选人，不改变已选成员；已选头像标签可移除。选好直接创建，群名由成员名生成，可在群资料中修改。
- 创建朋友、编辑资料、个人中心与群资料使用原生 dialog，保留原聊天与草稿。SSE 不重建未保存的表单。
- 头像使用显式按钮触发文件输入。文件值在读取后清空，支持反复选择同一文件。照片在本机解码，可拖动、方向键移动和缩放；使用头像只更新预览，保存资料才提交 128px 缩略图。取消恢复原预览，错误显示在当前表单。裁剪阶段隐藏背后的编辑面，关闭后恢复。
- 三款独立生成的照片预设作为可选头像，与既有 12 种图案兼容；不覆盖已有成员或用户的头像设置。
- 回复等辅助动作在鼠标悬停或键盘聚焦时出现；触屏仍有可见操作入口。表情选择写入草稿，不自动发送。
- 长资料、动态和 HTML 成果按需浮动展示；HTML 仍使用独立的 sandbox，源码以文本显示。

## 实现边界

`glass.css` 统一这次选定视觉的布局、色彩和交互状态；`glass.js` 管理短暂浮层、图片裁剪和窗口尺寸变化。已有 `app.js` 保留消息、Markdown、成果与 API 流程，`im.js` 保留资料和群编辑。后台只扩展了可用头像预设，不修改 BOT 的参与、上下文或费用逻辑。

玻璃采用 CSS backdrop-filter 和柔光背景素材，不宣称等同于 macOS 原生 Liquid Glass 光学渲染。不支持 backdrop-filter 的环境使用实色表层；减少透明度与减少动效偏好有对应降级。当前实际浏览器验收为 Chromium；Safari 的原生文件选择与移动端软键盘仍需真机体验。

验收截图、交互脚本和结果记录在 `output/playwright/glass-20261107/`。视觉对照见项目根目录 `design-qa.md`。
