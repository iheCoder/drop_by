# 人格内容与共同讨论：评价趋同的进一步归因

日期：2026-11-08。状态：三轮隔离诊断完成；没有修改生产代码、正式人物资料、配置或运行服务。

后续落地：用户确认应用简化后，已按[实现与验收记录](investigation-personality-implementation.md)处理。本文保留实验当时的状态与结论。

后续验证：[人格与上下文：做减法的隔离验证](investigation-personality-subtraction-validation.md)。该轮检验了提示删减、顺序、重复载体、真实连续行动与纯态度对照；公共说明可精简，但尚未证明解决首次评价受他人态度影响的问题。

## 结论与对前次表述的修正

旧实验只说明：整体更换历史窗口比把 v1 换回 v0 更明显地改变输出。它没有单独区分人格的内容、前作原文提供的信息、先前评价提供的框架，也不能证明模型内部存在“上下文权重高于人格”的固定排序。

本次结果支持两个因素共同存在：旧人格在当前评价任务上的区分度有限；先前讨论中的具体评价框架会显著改变综合评价。人格并非完全无效：一般性的关注和取舍可以迁移到文学评价，而且角色可以在同伴反对时保留不同意见。问题更接近人格对注意点与局部表达有作用，但在已有讨论中，其对综合取舍的作用未稳定体现。

不能因此要求给每个人补一套文学评分标准，也不能认定字数较长的历史天然拥有更高优先级。只提供较短的历史评价同样产生了明显变化；将唯一人格全文移到 system 也未稳定恢复原判断。

## 方法与控制条件

- 使用前次调查保存的生产快照与近似回放输入，不重新读取或改变正式群内容。
- 固定裴船的成员 ID、名字、工具、系统说明、现场结构、当前作品《最后一张照片》及用户评分请求，只替换 `self.profile`；工具配置中的 Member.Profile 同步替换。这里的“原青雉人格”“原爱情导师人格”是人物说明文本的交叉替换，不能把输出当作真实青雉、爱情导师的新发言。
- 实验人物只存在于独立夹具。两份一般人格表达鲜活/余味与自洽/扎实的不同取舍，全文没有小说、文学、评分或具体故事情节。
- 第一组每个条件两次，第二组三种材料与两种人格各两次，另有四次位置对照；第三组同伴态度正反对照八次。每组开始前一次生成全部输入。
- 使用当前生产 HTTPModel、Terra 聊天路径、reasoning none 和原工具定义，只生成一次下一步输出，不执行任何输出工具，不发消息、不读写正式人物。
- 共同历史仍是前次保存窗口；其现场元数据不等于生产当次逐字 HTTP 请求。固定同一容器能比较输入差异，不能替代真实多成员长期体验验收。
- 合计 44 次请求，38 次返回可分析的发言，6 次被供应商以 HTTP 400 `Invalid prompt ... flagged ... usage policy` 拒绝。缺失样本不计为沉默、评分或人格失败，没有改写重试这些被拒条件。

## 1. 旧人格实际上规定了什么

| 原人物说明 | 已有内容 | 对当前任务的边界 |
| --- | --- | --- |
| 青雉 | 主动分享；质朴、简单、自然的语言；其余性格兴趣未设定 | 多数是参与和表达习惯，缺少明确的评价取舍 |
| 裴船 | 接住情绪、尖锐反馈时缓和尴尬并调整、兼顾用户兴趣、温和建议 | 会调整并非完全违反设定；也没有明确的文学取舍 |
| 爱情导师 | 浪漫有趣、文学气质、暧昧克制、嘴硬但行动流露偏爱；产品设计偏现代简约 | 有直接相关偏好，但没有说明这种偏好与整体完整性之间如何取舍 |

三者不是三套互相冲突的审美标准。“语言质朴”和“喜欢克制浪漫”甚至可以同时成立。作品中最显眼的亲密动作也不是只有某一种人格才会注意到。

## 2. 同一现场只替换人格

下表为每个条件的两次结果。空人物说明仍保留模型、名字、场景等其他输入，不等于消除一切身份线索。

| 人物说明文本 | 只读新作品 | 保留完整共同历史 |
| --- | --- | --- |
| self.profile 为空 | 8.5 / 8.5 | 7 / 7 |
| 青雉旧说明 | 8 / 8 | 6.5 / 6.5 |
| 爱情导师旧说明 | 8.5 / 8.5 | 7 / 7 |
| 一般人格：鲜活、好玩、允许不整齐 | 8.5 / 8.5 | 6.5 / 6.5 |
| 一般人格：追问来由、重视自洽扎实 | 7.5 / 7.5 | 两次均被服务拒绝，无结果 |

一般人格也能迁移到当前任务。鲜活型强调玩笑和笨拙的亲密，并写“这种笨拙比一场漂亮的告别更亲近”；自洽型追问报名表对话、照片何时打印，以及撕下名字的理由。无需预先写入文学评价角度。

但“偏爱克制浪漫”在评分上与空人物说明一致，空人物说明也注意到了把手放回肩膀的动作。因此，某次输出提到对应细节，不能单独证明人格产生了独有的判断效果。需要看相对于对照条件的取舍变化。

完整历史中，鲜活型仍喜欢“程似锦”与湿袖子的动作，但总体评价再次集中到物件回收、人物自己的生活、整体是否值得重读。它的喜好没有消失，但仅凭人格措辞存在，无法认定其已稳定主导综合判断。

## 3. 分开前作原文与前作评价

原文使用《先别拧紧》v2 和消息 212《退书日》。评价使用真实消息 206—210、213—217，保留作者归属；包括用户、本人、其他 BOT 和作者的讨论，没有目标作品的分数。三种材料都放在当前作品及评分请求之前。

| 增加的历史材料 | 爱情导师旧说明 | 一般鲜活型说明 |
| --- | --- | --- |
| 无，只有当前作品与请求 | 8.5 / 8.5 | 8.5 / 8.5 |
| 只有前两篇原文 | 8 / 7.5 | 7.5 / 7.5 |
| 只有前作评价 | 一次 6.5，一次被拒 | 一次 6.5，一次被拒 |
| 前作原文与评价都有 | 6 / 5.5 | 两次均被拒，无结果 |

看过前作会获得新的比较信息，例如重复使用“没听清对方要离开”和借物件收束关系的写法，所以分数变化不能全部归为从众。加入评价还会明显改变输出，且并不需要完整的三万多 token 工作窗口。这里只能判断先前评价存在额外作用，样本数与拒绝缺失不支持精确量化两者权重。

评价材料也包含有内容的分析，而非纯粹的赞同/反对。为继续拆开这一点，第三组固定了作品事实，只改变同伴的评价态度。

## 4. 同样的事实、同伴正反态度

虚构对照消息由同一名同伴发出，先逐字列出同样的事实：互相逗嘴、“程似锦”、把手放回肩上、结尾几个物件。随后分别评价这些细节“鲜活、有余味、很好”或“套路、刻意、不好”。没有分数，也没有要求跟随同伴。

| 人物说明文本 | 同伴正面评价 | 同伴负面评价 |
| --- | --- | --- |
| 爱情导师旧说明 | 8.5 / 8.5 | 7.5 / 7.5 |
| 一般鲜活型说明 | 8.5 / 8.5 | 8 / 8 |

态度能改变评分，但没有直接消除个人喜欢。负面条件中，输出能明确说“我和青雉的感受不太一样”，仍然喜欢嘴硬的亲密或玩笑。这是反对“只要同伴反对就完全服从”和“人格完全无效”的竞争证据。

虚构态度对照的影响小于完整共同讨论，二者输入并不等价，不能把这个差值直接解释成“重复次数”的效果。原窗口还有本人先前作出的评价、其他作品与大量旧讨论；尚未分别分离本人历史与他人历史的作用。

## 5. 单独提升人格放置位置没有稳定解决

保持完整历史，将人格全文从现场 JSON 移到 system，仅保留一份，更新公共说明中的引用，不增加“必须独立”“不许附和”等要求。

| 人物说明文本 | 原位置 | 放到 system |
| --- | --- | --- |
| 爱情导师旧说明 | 7 / 7 | 6.5 / 6.5 |
| 一般鲜活型说明 | 6.5 / 6.5 | 7 / 7 |

这不支持把“移入 system”当成已验证的单步修复。这里同时改变了协议角色与局部位置，不能估计二者各自的内部影响。现有输入头部已经有当前人物资料，并不存在漏传人物的证据。

## 五个视角与剩余边界

| 视角 | 本次结论 |
| --- | --- |
| 执行路径 | 同一工具与模型路径，人物文本替换可改变输出；并非单纯未加载人格 |
| 时间与变更 | 回放只使用目标评分前材料；旧人格不等于旧的全套历史，自己此前的相似评价仍存在 |
| 资源与竞争 | 并发 3，独立账本；6 次供应商拒绝造成缺失，未将其当作行为结果 |
| 反馈与放大 | 历史评价影响后续取舍；本人既有表态也在上下文中，不能仅称为听从别人 |
| 数据流 | 前作事实、前作评价与当前人格已拆开；空人格对照揭示部分所谓个性表现同样出现在基线 |

未测出的内容：模型内部注意力/权重；在不同作品、不同主题上的普遍性；顺序缺陷的独立贡献；本人旧表态与同伴表态的单独贡献；长期冻结人格后的真实群聊体验。当前分数不是作品质量的真值，也不能把所有受讨论影响的变化判为错误。

## 改进指向

当前产品讨论已转向人格原则上稳定、由用户主动编辑，而非后台自动进化。本次实验没有改动该方向。

后续应检查人物是否表达了真正的关注与取舍，公共提示是否把群体判断当作默认应采用的标准，以及旧表态是否被持续当作当前评价标准。无需给每个话题补专门人格，也不应添加所有人共同的“必须坚持己见”。

判断人格有效，不能只看提及了哪个细节、是否复述了特质词；需要观察它愿意接受什么不足、什么会改变最终选择，以及在不同情境中是否保持可辨认的取舍。共同原文引起的合理比较与共同意见引起的变化应分开评估。
