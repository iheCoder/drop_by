# drop_by

一个由你和多个独立 AI 成员共同参与的持续聊天空间。成员可以群聊、私聊、互相接话，沿真实线索进行网页探索，把结果保存成可继续修改的文本成果。关闭网页不会停止服务端已经允许的工作。

当前实现面向 **macOS / Linux、本机单用户**。后端使用 Go 标准库 HTTP 服务，SQLite 保存聊天、经历、工作、工具记录和成果版本，前端为随二进制嵌入的原生 HTML / CSS / JavaScript，不需要 Node 构建或额外数据库服务。

## 启动

需要 Go 1.27；模块指定工具链 1.27.3。首次运行会下载工具链与 SQLite 驱动依赖。

```sh
# 在已有 OPENAI_API_KEY 的终端中运行，不要把真实密钥放进仓库。
go run ./cmd/dropby
```

打开 <http://127.0.0.1:8090>。先创建成员，填写方向与系统生成的情境问题，再逐个选择成员建群。成员资料页可以开启私聊；输入 `@` 可以点选成员。

如果当前网络无法连接默认 Go 代理，可以仅为本次命令指定镜像：

```sh
GOPROXY=https://goproxy.cn go run ./cmd/dropby
```

希望关掉终端后仍运行，可以构建后在后台启动：

```sh
go build -o bin/dropby ./cmd/dropby
mkdir -p data
nohup ./bin/dropby >data/server.log 2>&1 &
```

服务必须保持运行，电脑也必须处于可运行状态；关机、休眠时无法执行网络探索。重新启动会恢复中断的工作。停止服务用正常的 `SIGTERM` 或终端 `Ctrl+C`，程序会取消生成并保留未完工作。同一数据目录只允许一个服务进程。

本机通过 macOS 系统代理访问 OpenAI，当前代理地址为 `http://127.0.0.1:7790`。Go 不自动读取 macOS 系统代理；在这台机器手动重启时使用：

```sh
HTTPS_PROXY=http://127.0.0.1:7790 NO_PROXY=localhost,127.0.0.1,::1 go run ./cmd/dropby
```

代理地址以本机实际设置为准；当前后台实例已经带上该代理环境。

## 模型、工具和费用

默认模型是 OpenAI `gpt-5.6-sol`，默认读取 `OPENAI_API_KEY`，地址为 `https://api.openai.com/v1`。搜索与网页读取仍独立使用 `DEEPSEEK_API_KEY`，其费用不属于 OpenAI 赠送额度。密钥只保留在进程环境，不写入 SQLite、不传给浏览器、不写日志。没有模型配置时可以查看已有内容，不能创建成员或生成聊天；没有搜索配置时不会宣称已经联网探索。

可用环境变量见 [.env.example](.env.example)。程序**不自动加载 `.env` 文件**，请由启动环境设置变量。切换其他兼容 Chat Completions、JSON 输出与工具调用的模型服务，需要同时配置 `DROPBY_BASE_URL`、`DROPBY_API_KEY`、`DROPBY_MODEL`，并按该服务价格配置输入和输出费率；搜索服务仍独立配置。

| 变量 | 默认值 | 含义 |
| --- | --- | --- |
| `DROPBY_ADDR` | `127.0.0.1:8090` | 只允许本机回环监听 |
| `DROPBY_DATA_DIR` | `data` | 数据目录；每个目录独立 |
| `DROPBY_MODEL` | `gpt-5.6-sol` | 首版所有成员共享模型，身份、上下文、记忆与工具选择独立 |
| `DROPBY_DAILY_BUDGET_USD` | `3` | 每日估算费用上限 |
| `DROPBY_DAILY_CALLS` | `600` | 每日模型和联网工具调用总上限 |
| `DROPBY_INPUT_PRICE` / `DROPBY_OUTPUT_PRICE` | `4` / `20` | 每百万 token 的美元费率，用于保守估算 |
| `DROPBY_MAX_TURNS` | `5` | 一次交流机会最多发布的成员消息数 |
| `DROPBY_MAX_TOOL_ROUNDS` | `8` | 每次成员生成的模型/工具往返上限，最后一次只收尾；发布核对另计入日预算 |
| `DROPBY_MAX_OUTPUT_TOKENS` | `8000` | 快速调用的输出与推理 token 总上限 |
| `DROPBY_EXPLORE_INTERVAL` | `30m` | 后台提供探索判断机会的间隔；并非发消息的间隔 |

首句与后续探索采用同一 Sol 模型的不同推理配置：参与判断、控制理解和初步接话默认 `DROPBY_REASONING=none`；后续讨论、研究与成果生成使用 `DROPBY_DEEP_REASONING=high`，`DROPBY_DEEP_MAX_OUTPUT_TOKENS=25000`。这些是内部输出与推理额度，不要求成员写长回复。首句只开放后台安排工具，先给简短且有内容的回应；需要实际查证或创作时持久化工作，随后释放群的执行位，让研究继续。普通闲聊不强制安排研究。

模型费率依据 [OpenAI GPT-5.6 Sol 文档](https://developers.openai.com/api/docs/models/gpt-5.6-sol)，会随供应商定价变化，需同步调整。每日 3 美元按用户约 100 美元的月度赠送额度设置，应用不读取账户余额或赠送额度到期日；调用次数上限为 600，仍受费用上限约束。

费用在调用前事务性预留，成功返回 token 用量后按配置费率结算；未知结果保留保守预留。账本按 **Asia/Shanghai 的自然日**保存，重启不会清空，预算耗尽后未完工作等下一预算日恢复。实际服务商账单可能包含缓存折扣和价格变更，界面资源限制不等于精确账单。

联网工具目前采用 [DeepSeek Search & Fetch 官方接口](https://api-docs.deepseek.com/guides/search/)，搜索与读取按每次 0.00075 美元保守预留。深入推理与工具调用使用 OpenAI [Responses 推理接口](https://developers.openai.com/api/docs/guides/reasoning)，保留工具往返所需的加密推理项目，且设置 `store=false`；快速回应同样使用 Responses，Chat Completions 仅保留给原有兼容服务。请求都设置超时，失败不会伪造结果，也不会无限重试。

## 运行方式与边界

- 成员分别判断 `speak / explore / pass`，只有选中的成员继续行动；新消息发布后重新判断。明确 `@` 优先，普通文字提名不强制发言。没有成员愿意参与时保持安静。
- 用户消息、修订号和待处理工作在同一事务落盘。新消息会取消该聊天正在生成的内容；即使外部请求未及时取消，旧修订也不能发布回复、保存成果或改写记忆。
- 公开聊天和研究是不同工作。“先别聊”立即停止公开讨论，研究可继续；“不用研究”立即停止该聊天的研究。带具体对象的自然语言由模型结合现有工作解释；模型不可用时，精确停止短语仍立即生效。恢复、局部停止、改方向也可用自然语言表达。
- 研究完成先保存结果，再生成独立的分享判断机会；是否提醒用户由消息的 `notify` 决定。浏览器通知只有在用户点击“开启通知”、页面仍打开且处于后台时可用。关闭所有页面期间不会发系统推送，消息完整保留供回来查看。
- 初始成员工具由系统在搜索、阅读、文本成果池中选择；经历、历史检索等内部工具按当前情境提供。没有终端执行、第三方联系、消费、账户修改或公开发布工具。
- 经历用带来源的自然语言笔记表达，不做人格分数或关系数值。当前群原始聊天只对该群可用；成员可以携带自己的非敏感经验笔记进入其他群和私聊。敏感内容识别依赖模型，**尚不提供经过验证的跨场景保密保证**，验收应使用非敏感数据。
- 成果实际保存于 SQLite，修改生成新版本。浏览器可查看历史和下载 Markdown。HTML 与代码按文本显示，不执行；“可玩的程序”或外部发布不是当前工具能力。
- 消息、私聊、经历和成果保存前，额外核对实际行动与来源，防止“AI 自称坐过椅子”等虚构身体经历传播为事实；只修正事实归属与证据强度，不替成员决定观点。核对本身也调用模型并消耗预算，不能当作已经证明的绝对防幻觉保证。
- 单轮达到上限不会关闭群。未完成工具行动保留为后台研究；研究连续达到工具上限三次后暂停，用户可明确要求继续。模型或工具错误保留真实记录。普通模型故障由系统说明，工具失败由成员结合实际记录说明。
- 同一成员跨场景共享身份和可携带经历，不代表采用不同底层模型或独立事实来源；多个成员意见一致不能当作独立证据。

## 代码位置

| 文件 | 责任 |
| --- | --- |
| `cmd/dropby/main.go` | 服务启动、后台进程和退出 |
| `internal/dropby/store.go` | SQLite 事务、原始记录、工作恢复、数据目录锁 |
| `internal/dropby/engine.go` | 用户插话、成员参与、讨论与研究分离、有限运行 |
| `internal/dropby/model.go` | 实际模型 HTTP 请求、成员创建、预算预留 |
| `internal/dropby/tools.go` | 真实搜索、阅读、成果版本、记忆和主动私聊 |
| `internal/dropby/http.go` | 本机 API、SSE、请求验证与浏览器访问边界 |
| `internal/dropby/web/` | 创建成员、群聊、私聊、完整聊天、成果查看 |

## 检查与验收

```sh
go test -race ./...
go vet ./...
node --check internal/dropby/web/app.js
go build ./cmd/dropby
```

自动测试覆盖过时结果拒绝、即时停止、局部更正、并发预算、重启恢复、无人回应、研究独立完成、实际工具失败、成果版本、跨群记忆可见范围、HTTP 边界、历史分页、明确 `@` 优先，以及无浏览器连接时继续执行。测试中的模型替身仅用于注入确定性边界，生产代码没有模拟回复模式。

真实服务验收与体验观察记录在 [docs/verification.md](docs/verification.md)。功能通过并不等于“朋友群已经有趣”；自然错落、长期关系、主动内容是否值得收到，仍需持续真实使用验证。
